# docs 说明

本目录是**参考资料与历史归档**，不是权威来源。

## 权威来源是代码

本目录下的任何内容都可能落后于实现。判断"系统实际怎么做的"，一律以 `backend/` 与
`frontend/src/` 的代码、以及 `backend/tests/` 的用例为准，不要以文档为准。

## 交叉引用不可靠

文档之间的引用（形如"见 `待办/待办清单.md` B1 追加之三"）和章节号引用（`§2.1`、
行号 `:33` 这类）在后续编辑中**没有跟着维护**，可能已经指错位置或指空。读到引用对不上时，
请以被引文件的当前实际内容为准，或者直接在代码里找答案。
