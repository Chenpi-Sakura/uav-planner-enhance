# 无人机飞行决策平台

## 一、项目目标

构建一个集气象数据分析、飞行可行性评估、飞行时间窗口规划于一体的智能决策平台，实现对青藏高原地区无人机飞行任务的空间可行性评估和时间窗口优化两大核心功能，输出明确的“可飞/不可飞”结论及可执行的时间方案。

## 二、功能一：飞行路径可行性评估

### 2.1 功能描述

输入的起点（A点）和终点（B点），平台基于已有气象数据，计算湍流动能和湍流耗散系数判断周围湍流区域大小及强度，判断是否存在安全可行的飞行路径。

当条带状或块状高危险湍流区域面积过大、强度过高，导致无法规划出安全路径，或绕行成本超出可接受阈值时，平台输出“无法飞行”的明确结论。

## 三、功能二：飞行时间窗口规划

### 3.1 功能描述

针对输入的起点（A点）和终点（B点），平台基于一天内不同时段的湍流强度变化数据（三小时一次），寻找湍流强度最低的窗口期，确保无人机在整个飞行时段内均处于安全阈值以下。

若当日所有时段均无法满足安全飞行条件，则输出“今日不适合飞行”并预测最近的可飞行日期。

> 备注：这个还可以，这个做起来可能不会太难。

## 附：2026-09-26 追注（结论由两态扩为四态）

上文「输出明确的“可飞/不可飞”结论」是立项时的口径。实现过程中发现两态会把两种完全不同的情况
印成同一句话：**走廊确实封死**（算完了，不存在满足阈值的航线）与**这次没算完**（搜索达到展开
预算上限）。后者印成“不可飞”是假阴性——航线可能存在，只是没搜到，用户会据此取消任务。
现口径为四态：

| 结论 | 含义 | 期望的用户动作 |
| --- | --- | --- |
| 可飞 | 找到满足该档阈值的航线 | 按方案执行 |
| 不可飞 | 已算完，该档阈值下不存在安全航线 | 更换起降点 / 换时段 / 放宽阈值 |
| 超预算 | 有安全航线，但绕行成本超出该档可接受阈值 | 换更宽松的档位或换时段 |
| 未算出 | 达到展开预算上限仍未收敛，是否存在航线尚未确定 | 缩短航程、稍后重试或复核航程长度 |

「未算出」同时给出本次搜索花掉的力气（A\* 真正研究过的路口数 / 展开预算），三档卡片、评估详情、
时间窗口候选行与规划弹窗共用同一句措辞。功能二的“今日不适合飞行”同理，只在各时段都算完且均无解
时给出。
